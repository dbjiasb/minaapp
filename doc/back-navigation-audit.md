# 返回入口走查

日期：2026-11-10。范围：`biz/lib` 全项目返回按钮、退出回调及路由入口。

## 已修复

- 页面返回按钮统一使用 `AppBackButton`：本地图标、主题前景色、系统本地化的返回说明，常规布局下提供 48×48 点击区域。
- 聊天、私聊及深色个人资料等照片背景使用白色箭头和深色衬底；剧情页不再使用与背景相同的箭头颜色。
- 移除 AI 模式入口的嵌套点击处理；调整过窄或过矮的模式商店、角色编辑页导航区域。
- 会员页返回按钮置于内容之上，覆盖加载、失败和成功状态；修复窄屏底部链接溢出。
- 无标题网页在原生加载和错误状态提供返回入口；加载完成后仍使用网页自带导航。
- 匹配扫描及结果页统一等待退出确认和服务端清理：取消退出保留页面，请求失败保留页面，成功才返回；结果页同时拒绝当前匹配来电。连续返回不会重复打开确认或发起请求。
- 保留角色返回前保存、聊天返回前更新会话、生成页停止确认等原有业务回调。
