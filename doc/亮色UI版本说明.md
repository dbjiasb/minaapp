# 亮色 UI 版本

默认启用暖白背景、白色卡片、深灰文字和黄色品牌点缀。业务接口、路由与数据逻辑沿用现有项目。

## 已适配

- 登录入口：浅色渐变背景、品牌标识和黄色邮箱登录按钮。
- 应用底部导航：白色底、深色图标、黄色选中态，保留未读数和提醒。
- 发现页：浅色顶部栏，保留全屏图片、视频内容的遮罩。
- 角色首页：搜索、筛选、分类标签、白色信息区卡片、空状态和剧场列表。
- 消息：分类、推荐、会话名称、摘要、设置菜单。
- 个人中心：资料、余额卡片、功能区、伙伴列表、群组列表、编辑资料、设置、语言选择和关于页。
- 搜索和通用确认弹窗。
- 聊天：普通、私聊和剧场页面的背景、气泡、输入栏与顶部栏；消息菜单、聊天模型、图片和视频生成面板、礼物面板及 AI 数据授权弹窗。
- Moment：动态列表、详情、评论输入、发布、角色选择、生成图片和举报弹窗；移除嵌套顶部栏导致的多余状态栏占位。

通话、匹配、创作、充值、AI 模式、群组和资料页现已同步适配。完整范围与验证口径见《亮色UI全面检查清单》。

## 运行

在 `debug` 或 `dis` 模块运行，两个入口共用同一套业务 UI：

```sh
cd debug
flutter run --dart-define=LIGHT_UI=true
```

构建深色版本：

```sh
flutter run --dart-define=LIGHT_UI=false
```

这是构建配置，修改后需要重新启动，热重载不会切换该配置。配色定义在 `biz/lib/shared/app_theme.dart`。

## 验证

```sh
cd biz
flutter test test/light_ui_test.dart test/chat_light_ui_test.dart --no-pub
flutter test test/light_ui_test.dart --no-pub --dart-define=LIGHT_UI=false
flutter analyze --no-pub
```

聊天组件测试覆盖正文、旁白和译文在正常、大字号下的对比度、布局和点击。组件测试覆盖主文字、辅助文字的对比度，以及窄卡片在 1、1.5、2 倍字号下的布局与点击。静态分析仍有仓库原有的 lint 提示。完整 App 的登录、网络数据和原生设备效果需要在 iOS/Android 上验收。
