# 首页改造开发文档

## 项目概述

本文档记录了将 `home_page.dart` 改造为 Figma 设计稿样式的完整开发过程。

**设计稿链接**: https://www.figma.com/design/kH3LOCC3WQTI0aIjPEz0tm/%E6%96%B0%E9%A9%AC%E7%94%B2%E5%8C%85%E6%9C%AA%E5%91%BD%E5%90%8D2?node-id=0-2595&m=dev

**开发时间**: 2026-03-12

## 一、需求分析

### 1.1 原有架构
- 使用 TabBar + PageView 架构
- 仅显示一个 Theater 列表（Story tab）

### 1.2 新设计要求
- 顶部标题栏：显示 "Recommend" + 搜索图标
- 二级菜单栏：5 个 tab（Story、Discovery、Real、OC、Pro only）
- 内容区域：
  - Story tab：显示线性列表（复用原有 TheaterListView）
  - 其他 tab：显示瀑布流卡片网格（两列布局）
- 悬浮 Create 按钮：带滚动隐藏/显示动画
- 支持 tab 点击切换和左右滑动联动

- 角色名称、简介、标签

**关键代码**：
```dart
class RoleCardWidget extends StatelessWidget {
  final Map item;
  final VoidCallback onTap;
  final bool isRealType; // 是否是真人类型

  @override
  Widget build(BuildContext context) {
    String name = item['nickname'] ?? "";
    String coverUrl = item['coverUrl'] ?? "";
    String avatarUrl = item['avatarUrl'] ?? "";
    String bio = item['bio'] ?? "";

    // 如果是真人类型且 coverUrl 为空，使用 avatarUrl
    String imageUrl = coverUrl;
    if (isRealType && coverUrl.isEmpty && avatarUrl.isNotEmpty) {
      imageUrl = avatarUrl;
    }

    return GestureDetector(
      onTap: onTap,
      child: Container(
        width: 166.w,
        child: Stack(
          children: [
            // 背景图片
            ClipRRect(
              borderRadius: BorderRadius.circular(12.r),
              child: CachedNetImage(
                imageUrl: imageUrl,
                width: 166.w,
                height: 260.w,
                fit: BoxFit.cover,
              ),
            ),
            // 底部渐变遮罩
            Positioned(
              bottom: 0,
              child: Container(
                height: 120.w,
                decoration: BoxDecoration(
                  gradient: LinearGradient(
                    colors: [
                      Colors.transparent,
                      Colors.black.withValues(alpha: 0.8),
                    ],
                  ),
                ),
              ),
            ),
            // 内容区域
            Positioned(
              bottom: 12.w,
              child: Column(
                children: [
                  Text(name), // 角色名称
                  if (bio.isNotEmpty) Text(bio), // 简介（为空时不显示）
                  // 标签列表
                ],
              ),
            ),
          ],
        ),
      ),
    );
  }
}
```

**设计规范**：
- 卡片尺寸：166x260px
- 圆角：12px
- 左右间距：16px（左）+ 11px（中间）+ 16px（右）
- 字体：名称 14sp Bold，简介 12sp Normal，标签 10sp Medium
- 颜色：名称白色，简介 #b8b7b4，标签背景半透明

**特殊处理**：
- 标签支持字符串和 Map 类型
- bio 为空时不显示布局
- 真人类型且 coverUrl 为空时使用 avatarUrl

### 3.3 创建角色列表视图 (role_list_view.dart)

**功能**：
- 瀑布流布局（2 列）
- 下拉刷新和上拉加载更多（使用 pull_to_refresh 插件）
- 支持不同角色类型
- 空数据状态显示

**关键代码**：
```dart
class RoleListView extends StatelessWidget {
  final RoleListType type;
  final ScrollController? scrollController;

  @override
  Widget build(BuildContext context) {
    final controller = Get.put(
      RoleListLogic(type: type, externalScrollController: scrollController),
      tag: type.toString(),
    );

    return Obx(
      () => controller.isLoading.value
          ? Center(child: CircularProgressIndicator(color: AppColors.primary))
          : SmartRefresher(
              controller: controller.refreshController,
              enablePullDown: true,
              enablePullUp: true,
              onRefresh: controller.onRefresh,
              onLoading: controller.onLoading,
              child: controller.dataList.isEmpty
                  ? _emptyView(controller)
                  : MasonryGridView.count(
                      physics: AlwaysScrollableScrollPhysics(),
                      padding: EdgeInsets.symmetric(horizontal: 16.w, vertical: 12.w),
                      crossAxisCount: 2,
                      crossAxisSpacing: 11.w,
                      mainAxisSpacing: 12.w,
                      controller: controller.scrollController,
                      itemBuilder: (context, index) => RoleCardWidget(
                        item: controller.dataList[index],
                        isRealType: type == RoleListType.real,
                        onTap: () {
                          RouteHelper.toChatTheater(controller.dataList[index]);
                        },
                      ),
                      itemCount: controller.dataList.length,
                    ),
            ),
    );
  }

  Widget _emptyView(RoleListLogic controller) {
    return GestureDetector(
      onTap: () {
        controller.initData();
      },
      child: ListView(
        physics: AlwaysScrollableScrollPhysics(),
        children: [
          SizedBox(height: 200.w),
          Center(
            child: Text(
              Copywriting.security_no_data,
              style: TextStyle(
                color: Colors.white,
                fontSize: 16.sp,
                fontWeight: FontWeight.normal,
              ),
            ),
          ),
        ],
      ),
    );
  }
}
```

**pull_to_refresh 特性**：
- `SmartRefresher`：智能刷新组件
- `enablePullDown`：启用下拉刷新
- `enablePullUp`：启用上拉加载
- `RefreshController`：控制刷新状态
- 支持自定义刷新头和加载尾

### 3.4 创建角色列表控制器 (role_list_logic.dart)

**功能**：
- 数据加载和分页
- 使用 pull_to_refresh 管理刷新状态
- 支持外部 ScrollController

**关键代码**：
```dart
enum RoleListType {
  ai,
  real,
  ugc,
  proOnly,
}

class RoleListLogic extends GetxController {
  final RoleListType type;
  final ScrollController? externalScrollController;

  late final ScrollController scrollController;
  final RefreshController refreshController = RefreshController(initialRefresh: false);
  final RxBool isLoading = true.obs;
  final RxList dataList = RxList<Map>();
  bool isLoadingMore = false;
  bool _hasMore = true;
  int page = 0;
  int pageSize = 20;

  @override
  void onInit() {
    scrollController = externalScrollController ?? ScrollController();
    super.onInit();
    initData();
  }

  @override
  void onClose() {
    if (externalScrollController == null) {
      scrollController.dispose();
    }
    refreshController.dispose();
    super.onClose();
  }

  void initData() {
    isLoading.value = true;
    getListData();
  }

  void onRefresh() async {
    page = 0;
    _hasMore = true;
    await getListData();
    refreshController.refreshCompleted();
  }

  void onLoading() async {
    if (!_hasMore) {
      refreshController.loadNoData();
      return;
    }
    page++;
    await getListData();
    if (_hasMore) {
      refreshController.loadComplete();
    } else {
      refreshController.loadNoData();
    }
  }

  rm.RoleListType _mapToRoleManagerType() {
    switch (type) {
      case RoleListType.ai:
        return rm.RoleListType.ai;
      case RoleListType.real:
        return rm.RoleListType.real;
      case RoleListType.ugc:
        return rm.RoleListType.ugc;
      case RoleListType.proOnly:
        return rm.RoleListType.pro_only;
    }
  }

  Future<void> getListData() async {
    try {
      ApiResponse rsp = await rm.RoleManager.instance.getRoleList(
        pageIndex: page,
        pageSize: pageSize,
        type: _mapToRoleManagerType(),
      );

      if (rsp.isSuccess) {
        List rawData = rsp.data[Security.security_param] ?? [];
        List<Map> data = rawData.cast<Map>();

        if (page == 0) {
          dataList.clear();
        }

        dataList.addAll(data);
        _hasMore = rsp.data[Security.security_hasMore] == true;
      }
    } catch (e) {
      // Error handled silently
    } finally {
      isLoading.value = false;
      isLoadingMore = false;
    }
  }
}
```

**RefreshController 状态管理**：
- `refreshCompleted()`：刷新完成
- `loadComplete()`：加载更多完成
- `loadNoData()`：没有更多数据
- `dispose()`：释放资源

**数据结构**（参考 VirtualRoleItem）：
```dart
{
  'nickname': '角色名称',
  'coverUrl': '封面图片URL',
  'avatarUrl': '头像URL',
  'bio': '简介',
  'uid': '用户ID',
  'tags': ['标签1', '标签2'],
  'acType': 账号类型
}
```

```dart
class HomePageView extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final controller = Get.put(
      HomePageViewController(),
      tag: 'home_page_${DateTime.now().millisecondsSinceEpoch}',
    );

    return Scaffold(
      body: SafeArea(
        child: Stack(
          children: [
            Column(
              children: [
                _buildTopBar(), // 顶部标题栏

                // 二级菜单
                Obx(() => CategoryTabsWidget(
                  categories: controller.categories,
                  selectedIndex: controller.selectedCategoryIndex.value,
                  onTap: (index) => controller.onCategoryChanged(index),
                )),

                // TabBarView
                Expanded(
                  child: TabBarView(
                    controller: controller.tabController,
                    children: [
                      TheaterListView(scrollController: controller.scrollController),
                      RoleListView(type: RoleListType.ai, scrollController: controller.scrollController),
                      RoleListView(type: RoleListType.real, scrollController: controller.scrollController),
                      RoleListView(type: RoleListType.ugc, scrollController: controller.scrollController),
                      RoleListView(type: RoleListType.proOnly, scrollController: controller.scrollController),
                    ],
                  ),
                ),
              ],
            ),

            // 悬浮 Create 按钮
            Positioned(
              bottom: 16.w,
              child: Obx(() => AnimatedOpacity(
                opacity: controller.showCreateButton.value ? 1.0 : 0.0,
                duration: Duration(milliseconds: 200),
                child: AnimatedSlide(
                  offset: controller.showCreateButton.value ? Offset.zero : Offset(0, 0.5),
                  duration: Duration(milliseconds: 200),
                  child: _buildCreateButton(),
                ),
              )),
            ),
          ],
        ),
      ),
    );
  }
}
```

**控制器**：
```dart
class HomePageViewController extends GetxController
    with GetSingleTickerProviderStateMixin {
  final List<String> categories = ['Story', 'Discovery', 'Real', 'OC', 'Pro only'];
  final RxInt selectedCategoryIndex = 0.obs;
  final RxBool showCreateButton = true.obs;
  final ScrollController scrollController = ScrollController();
  Timer? _scrollTimer;
  late TabController tabController;

  @override
  void onInit() {
    super.onInit();
    tabController = TabController(length: categories.length, vsync: this);

    // 监听 TabController 变化，同步更新 selectedCategoryIndex
    tabController.addListener(() {
      if (!tabController.indexIsChanging) {
        selectedCategoryIndex.value = tabController.index;
      }
    });

    _setupScrollListener();
  }

  void _setupScrollListener() {
    scrollController.addListener(() {
      // 滚动时隐藏按钮
      if (showCreateButton.value) {
        showCreateButton.value = false;
      }

      _scrollTimer?.cancel();

      // 滚动停止 150ms 后显示按钮
      _scrollTimer = Timer(Duration(milliseconds: 150), () {
        if (!isClosed) {
          showCreateButton.value = true;
        }
      });
    });
  }

  void onCategoryChanged(int index) {
    // 点击 tab 时切换页面
    if (!tabController.indexIsChanging && tabController.index != index) {
      selectedCategoryIndex.value = index;
      tabController.animateTo(index);
    }
  }

  @override
  void onClose() {
    _scrollTimer?.cancel();
    scrollController.dispose();
    tabController.dispose();
    super.onClose();
  }
}
```

**关键特性**：
1. **使用唯一 tag 创建 Controller**：避免退登后重新登录时使用已 dispose 的 controller
2. **TabBar 和 TabBarView 联动**：
   - 点击 tab：调用 `tabController.animateTo(index)`
   - 滑动页面：监听 `tabController` 更新 `selectedCategoryIndex`
3. **共享 ScrollController**：所有子页面使用同一个 ScrollController，实现统一的滚动动画
4. **Create 按钮动画**：
   - 滚动时立即隐藏
   - 滚动停止 150ms 后显示
   - 使用 `AnimatedOpacity` 和 `AnimatedSlide` 实现渐变和位移

## 四、关键问题与解决方案

### 4.1 TabController dispose 后仍被使用

**问题**：退登后重新登录报错 "A TabController was used after being disposed"

**原因**：GetX 缓存了已 dispose 的 controller

**解决方案**：
```dart
// 使用唯一 tag 创建 controller
final controller = Get.put(
  HomePageViewController(),
  tag: 'home_page_${DateTime.now().millisecondsSinceEpoch}',
);

// 在 Timer 回调中检查 controller 状态
_scrollTimer = Timer(Duration(milliseconds: 150), () {
  if (!isClosed) {
    showCreateButton.value = true;
  }
});

// 在 onCategoryChanged 中检查 TabController 状态
void onCategoryChanged(int index) {
  if (!tabController.indexIsChanging && tabController.index != index) {
    selectedCategoryIndex.value = index;
    tabController.animateTo(index);
  }
}
```

### 4.2 标签数据类型不一致

**问题**：tags 字段可能是字符串数组或 Map 数组，导致类型转换错误

**解决方案**：
```dart
List<String> tags = [];
try {
  List rawTags = item['tags'] ?? [];
  for (var tag in rawTags) {
    if (tag is String) {
      tags.add(tag);
    } else if (tag is Map) {
      String tagName = tag['name'] ?? tag['title'] ?? tag.toString();
      tags.add(tagName);
    }
  }
} catch (e) {
  tags = [];
}
```

### 4.5 getListData 返回 void 导致编译错误

**问题**：在 onRefresh 和 onLoading 中使用 `await getListData()` 报错 "Uses 'await' on an instance of 'void'"

**原因**：getListData() 方法最初声明为 `void`，不能使用 await

**解决方案**：
```dart
// 将 getListData 改为返回 Future<void>
Future<void> getListData() async {
  try {
    ApiResponse rsp = await rm.RoleManager.instance.getRoleList(...);
    // ...
  } catch (e) {
    // ...
  } finally {
    isLoading.value = false;
    isLoadingMore = false;
  }
}

// 在 onRefresh 和 onLoading 中正常使用 await
void onRefresh() async {
  page = 0;
  _hasMore = true;
  await getListData();
  refreshController.refreshCompleted();
}
```
